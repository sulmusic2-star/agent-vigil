# Control release gate: commercial path

## Product

Agent Vigil should sell one result:

> **An AI-control update cannot reach production until independent evidence matches the exact artifact and deployment.**

The free CLI creates and verifies portable evidence. The paid service operates the independent challenge, observer, signing, retention, and protected deployment decision.

## Buyer

The likely owner is a platform-security, AI-platform, developer-productivity, or release-engineering team responsible for agent policy and production promotion. The paid unit should be a protected control stack or production environment, not a developer seat.

## Paid capabilities

- App-owned deployment checks for private and internal repositories;
- managed challenge, observer, admission, and deployment signing;
- scheduled recertification when an agent, model, policy, connector, or runtime changes;
- retained decisions and audit search;
- fleet-wide holds when a previously working control route regresses;
- customer KMS or workload identity, key rotation, exceptions, SIEM export, SSO, RBAC, data residency, self-hosting, support, DPA, and MSA.

## Value test

Measure value in each pilot:

`annual value = avoided control-regression loss + review time saved + audit preparation saved - operating friction`

A technical run is not a successful pilot. A pilot passes only when the organization keeps the gate enabled for another release and identifies a decision or audit task it would otherwise have missed or handled manually.

## Evidence ladder

1. Reproduce pass and rejection paths in one disposable public repository.
2. Gate one real released-agent or control update.
3. Install in five externally owned protected environments.
4. See at least three teams use it for a second release.
5. Convert two written-scope pilots at a price that tests a real budget owner.
6. Earn one renewal or expansion.

The revenue equation is ordinary:

`annual recurring revenue = retained paying organizations × realized annual contract value`

A million-dollar outcome is arithmetically possible at enterprise contract values. It is not likely or proven until outside teams retain, pay, and renew.

## Stop conditions

Stop expanding the enterprise surface if qualified teams will not make the rule mandatory, will not use it for a second release, or say their existing CI and review process is sufficient. Do not build a large dashboard before the live gate and retained outside use exist.

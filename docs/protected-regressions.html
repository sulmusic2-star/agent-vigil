Protected regression checks

Green tests.
Wrong answer.

A change can break a function and rewrite its tests to agree. Keep the expected answers outside that change.

Try it locally

No account or upload. Git and Docker required. Limited to dependency-free Node functions.

The mistake is small. So is the fix to the test.

Proposed implementation

exports.add = (a, b) => a - b;

Proposed test

assert.equal(add(2, 3), -1);

PASS: the changed test agrees.

Protected expectation

arguments: [2, 3]
expected:  5
observed: -1

FAIL: the expected behavior changed.

The controller keeps the approved answer. Candidate code runs in a separate, restricted container.

Constructed example, not a customer incident. A matching answer covers only the selected case.

Try one function first.

  1. In this source checkout, build and check the tools:
    npm ci --ignore-scripts
npm run build
node dist/cli.js regression doctor
  2. From your repository, create a case using the built CLI:
    node /path/to/agent-vigil/dist/cli.js regression init \
  --module src/math.cjs --export add \
  --args '[2,3]' --expect '5'
    Review the new .vigil-regressions.json, add useful cases, then commit it to the approved base.
  3. Check a proposed commit:
    node /path/to/agent-vigil/dist/cli.js regression check \
  --base FULL_BASE_SHA --head FULL_HEAD_SHA

This does not install a required GitHub check. These commands describe the source preview, not a feature promised in the currently published npm package.

Setup, intentional changes and security limits

One result. No hidden approval.

ResultWhat it means
PASSThe selected answers matched twice on each revision. Other behavior was not checked.
FAILA protected answer changed consistently. Fix it or request a separate contract review.
NOT CHECKEDEvidence is missing or inconsistent, or expectations changed. Do not treat it as success.

You can do this with ordinary CI.

We include an independent CI script that preserves the same answers. It may be all you need. Vigil adds input checks, setup diagnostics and a consistent receipt; not exclusive access to a new kind of testing.

Keep your existing tests and review tools. This preview does not import arbitrary test suites, install dependencies or prove all code is safe. A program can recognize test inputs; two repeats cannot establish that it is never flaky.

This local preview is free. It does not offer a hosted installation or a subscription. No receipts are uploaded.

Agent Vigil How the check works

For pull requests written with coding agents

Check the PR before you merge it.

The agent says the fix is done. Agent Vigil shows which commit and commands were checked, what failed, and what still needs checking.

What it checks

  1. The exact base and proposed commit.
  2. The commands the repository required.
  3. Whether the change stayed inside the task.
  4. Whether a regression test fails before the fix and passes after it.

Run it in your repository

The CLI is open source and runs on your machine or GitHub runner. Agent transcripts do not have to leave the repository.

npx @sulmusic/agent-vigil protect
What does INCONCLUSIVE mean?

The check could not verify something the task required. It does not turn missing evidence into a pass.

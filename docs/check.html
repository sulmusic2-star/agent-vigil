    What happens next

    Observation first. Enforcement second.

    1. Check the public record. The browser receipt records exact commit identity, formal reviews, check counts, freshness, and missing coverage.
    2. Inspect the limits. This page does not run trusted repository tests or decide whether those tests were sufficient.
    3. Install the repository gate. The copied v0.22.0 command prepares an exact-pin workflow and base-owned policy for review.
    4. Make the check required. A repository owner must configure enforcement. A prepared workflow alone does not protect merges.

    Downloaded receipts contain normalized counts, commit IDs, endpoint hashes, and decision fields. They omit response bodies, check logs, review text, source, prompts, and transcripts.

    Agent Vigil reports what it observed and what remains missing. Public evidence never authorizes deployment.
